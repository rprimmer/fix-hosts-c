\begin{abstract}
This document specifies the externally significant behavior of the C
implementation of \texttt{fix-hostfiles}.  It defines the program state,
primitive transformations, command semantics, algebraic laws, failure
boundaries, and the refinement map to the C modules.  Particular attention is
given to exact DNS matching, observational idempotence, backup history, and
atomic replacement of the active hosts file.
\end{abstract}
