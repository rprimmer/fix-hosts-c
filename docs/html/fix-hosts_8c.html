◆ removeHostEntry()

int removeHostEntry ( const char * hosts_path,
const char * dns_name )

Atomically remove hosts-file lines containing an exact DNS token.

The original file is first copied to a .bak file. Retained lines are written to a same-directory temporary file, synchronized, assigned the original permissions and ownership, and atomically renamed over the hosts file.

Parameters
hosts_pathPath to the active hosts file.
dns_nameValidated DNS token to remove.
Returns
EXIT_SUCCESS on success; EXIT_FAILURE on any filesystem error.
